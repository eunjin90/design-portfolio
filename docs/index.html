USER FLOW

화면을 연결한 주요 이용 흐름

버튼을 선택했을 때 다음 화면으로 자연스럽게 이어지도록 주요 이동 경로를 연결했습니다.

01
사이드 메뉴

메뉴 버튼을 누르면 사이드 메뉴가 열리고, 메뉴 항목을 선택해 해당 화면으로 이동하는 흐름

02
스탬프와 쿠폰

스탬프 버튼을 눌러 적립 현황을 확인하고, 쿠폰 메뉴를 선택해 쿠폰 화면으로 전환되는 흐름

03
상품 선택

카테고리와 상품 목록에서 원하는 상품을 선택하고 상세 화면으로 이어지는 구성

04
상품 수량 및 가격

상품 수량을 변경하면 선택 수량에 맞는 금액을 확인할 수 있도록 구성

05
로그인

로그인 화면과 앱 이용 화면을 연결해 사용자가 서비스에 진입하는 흐름 구성

PRODUCT SORTING

정렬 기준에 따라 달라지는 상품 목록

상품 목록에서 정렬 기준을 선택하면 해당 순서로 상품이 바뀌도록 연결했습니다. 인기순, 낮은 가격순, 높은 가격순, 신상품순을 각각 선택해 확인할 수 있습니다.
